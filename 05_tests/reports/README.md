# Test Reports

This directory stores consolidated test execution reports.

## Report Format

Each test execution generates a single Markdown report file:

```
reports/
├── TEST_REPORT_2026-07-22_18-30-00.md
├── TEST_REPORT_2026-07-21_14-15-00.md
└── ...
```

## Report Contents (ASPICE-Aligned)

Each report contains:

| Section | Content |
|---------|---------|
| Summary | Table with all ASPICE test levels |
| L1_SWE4_unit | Unit test results (or "NOT EXECUTED") |
| L2_SWE5_integration | Integration test results (or "NOT EXECUTED") |
| L3_SWE6_qualification | SW Qualification results (or "NOT EXECUTED") |
| L4_SYS5_acceptance | System Qualification (always "NOT EXECUTED" - manual) |
| Failed Tests | List of failed tests with error messages |
| Environment | SDK version, Gradle version, device info |

## Generating Reports

### Recommended: Use Master Script

```bash
# Run all tests and generate report
./05_tests/infra/scripts/run-all-tests.sh

# Report output: 05_tests/reports/TEST_REPORT_YYYY-MM-DD_HH-MM-SS.md
```

### Manual Report Generation

```bash
# After running tests manually, generate report
./05_tests/infra/scripts/generate-report.sh
```

## Viewing Latest Report

```bash
# Find latest report
ls -t 05_tests/reports/TEST_REPORT_*.md | head -1

# View in terminal
cat $(ls -t 05_tests/reports/TEST_REPORT_*.md | head -1)

# Or open in editor
code $(ls -t 05_tests/reports/TEST_REPORT_*.md | head -1)
```

## Git Ignore

Reports are typically not committed. The `.gitignore` should include:

```
05_tests/reports/TEST_REPORT_*.md
!05_tests/reports/README.md
```

---

*Reports are generated by `generate-report.sh` and contain all ASPICE test levels.*
